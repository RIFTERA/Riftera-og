# RIFTERA

A fantasy game-world NFT collection on BNB Chain — 1,111 chibi-pixel Rifters across three factions: Riftwardens, Stormcallers, and Voidborne.

- **Supply:** 1,111 (Free lane IDs 1–444 · Paid lane IDs 1001–1667)
- **Free:** 444 · 0 BNB · max 3 per wallet · Common only · requires a Binance Agent ID
- **Paid:** 0.001 BNB · max 5 per wallet · Common / Rare / Legendary
- **Utility:** Rift Shards game — full access for paid holders

## Metadata & images

Served from this repo via GitHub Pages:

- baseURI: `https://riftera.net/nft/metadata/`
- Layout: `nft/metadata/free/<id>.json`, `nft/metadata/paid/<id>.json`, images under `nft/images/`
